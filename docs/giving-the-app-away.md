# Giving the app away — the credentials are safe, the shelf travels

Moved out of `AGENTS.md` when it reached the instruction budget. This is the note
for anyone packaging or handing the app to a customer.

The owner hands this app to customers for free, and **their** provider keys are
theirs: the bundle carries no `.env`, no `credentials.json`, no signing key and no
fleet roster, the shipped `voices.json` is deliberately empty, and the app mints its
own `GATEWAY_API_KEY` on first run. Nothing of his leaves his Mac.

## The private Content Pack shelf is import-only

A customer's Mac has **no Story Studio source**, and since 2026-09-22 the Gateway
does not want one: the authoring surface was removed, and the shelf is a publisher,
not an author. There is no authored-vs-imported branch anywhere.

- **The historical identities ship.** `gateway/data/historical-identities.json`
  (regenerated by `store-analysis/export_historical_identities.py`) carries the
  baseline revision and the 180 historical pack and family ids — the exact set a
  private shelf must never reissue — and no key material. `setup()` reads this list
  and **fails closed** if it is missing: never a silently unguarded authority.
- **An imported pack states its own identity.** `_archive_metadata` reads everything
  from the archive's own manifest: item ids from `items[]`, title / description /
  tags from its documents, and `product_id` / `family` from the manifest's
  `entitlement` (`pack.` → `sku.`/`family.` only when a pack declares none) — so a
  pack keeps the identity it was built under instead of acquiring a new one per
  install. Its receipt records *this shelf's import* (`import:<sha256>`).
- **Story's tag cap is applied by hand here.** Thirteen tags once emptied the whole
  catalogue, and no parser runs on this path, so the trim to twelve is explicit.
- **The customer action is one step**: `POST /api/content-library/import-and-publish`
  (console: *Add a pack someone sent you* → **Add to shelf**) imports and publishes
  an emailed `.sspack` under **their** authority. There is no acknowledgement step
  and no review tab.
- **The Ed25519 signer is untouched.** `gateway/content_signing.mjs` still signs the
  release with the shelf's own key, which is what makes it a publisher.

So sending someone a new pack is: email the `.sspack`. Regenerate the shipped
identity list only if new *historical* Store packs are ever authored — the
re-authored library sits above the baseline and never needs it.
