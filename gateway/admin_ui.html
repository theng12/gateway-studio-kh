Preserved archives

        
Archive-only storage for `.sspack` inputs. Each archive carries its own name, description, kind and identity, so importing asks you for nothing — choose one file, several, or a whole folder. Import validates safety and hashes but does not create ownership, publish a release, or install a pack. Review an eligible archive here before adding it to the private shelf.
